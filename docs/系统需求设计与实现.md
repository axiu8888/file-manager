# kiftd 网盘系统 — 需求 · 设计 · 实现

本文档描述基于原版 kiftd 重写的前后端分离网盘系统：功能需求、总体设计与当前实现要点。

| 项 | 说明 |
|----|------|
| 后端 | `kiftd-backend/` Spring Boot 3.5 + PostgreSQL + Flyway |
| 前端 | `kiftd-front/` Vite + Vue3 + TypeScript + Element Plus |
| 参考 | `kiftd/` 原版包（只读参考，勿改） |
| 可选库 | `docker-compose.yml` 提供 PostgreSQL 16 |

---

## 1. 系统需求

### 1.1 目标

提供可自建的个人/小团队网盘：目录浏览、上传下载、在线预览、外链分享、基础 WebDAV，能力对齐原版 kiftd 的核心场景。

### 1.2 角色与权限

| 角色 | 能力 |
|------|------|
| 匿名访客 | 浏览约束为公开的目录；预览公开资源；通过外链下载 |
| 登录用户 | 在授权范围内新建文件夹、上传、改名、删除、移动/复制、下载、打包、搜索、改密 |
| 管理员 | 启动时自动初始化账号；可配置是否开放注册 |

细粒度权限（账户 `account_auth` 字段，逗号分隔）：

- `CREATE_NEW_FOLDER` — 新建文件夹
- `UPLOAD_FILES` — 上传
- `DELETE_FILE_OR_FOLDER` — 删除
- `RENAME_FILE_OR_FOLDER` — 重命名
- `DOWNLOAD_FILES` — 下载 / 外链 / 打包
- `MOVE_FILES` — 剪切、复制、粘贴

### 1.3 功能需求

#### 账号

- 登录 / 注册 / 修改密码
- 密码经 RSA 公钥加密传输，服务端私钥解密后再 BCrypt 存储
- 登录/注册支持图形验证码
- 注册可由配置开关关闭
- JWT 会话，默认有效期可配置（如 72 小时）

#### 目录与文件

- 树形目录（根目录固定为 `root`）
- 文件夹约束：公开浏览 / 需登录
- 新建、重命名、删除（文件夹递归）
- 文件上传、下载、重命名、删除
- 批量删除
- 按名称搜索文件夹与文件
- 剪切 / 复制 / 粘贴（冲突策略：覆盖 / 跳过 / 保留两者）
- 选中文件打包 ZIP 下载
- 上传整个本地文件夹（按相对路径自动建目录）
- 大目录分段加载（首屏 + 续载）
- 当前目录统计：递归子文件夹数、文件数、占用体积

#### 预览

| 类型 | 需求 |
|------|------|
| 图片 | 同目录图库浏览 |
| 音频 | 同目录播放列表 |
| 视频 | 在线播放；非 mp4 可转码（可选 FFmpeg） |
| PDF | 在线阅读，支持目录大纲 |
| Office | Word(docx) 转 PDF 预览；其它 Office 类型可降级提示 |
| EPUB | 电子书分页/滚动阅读 |
| 文本 | txt/log/css/js/json 等源码阅读 |
| Markdown | 类 VS Code：源码 / 并排 / 预览三模式 |
| HTML | 沙箱 iframe 预览 |

#### 分享与系统

- 文件直链（chain，较长有效期）
- 下载密钥（download-key，较短有效期）
- 系统公告展示与更新
- 系统 OS / 同步时间等信息展示
- 基础 WebDAV（列目录、上传、下载、删、建目录）

### 1.4 非功能需求

- 前后端分离；前端开发态 CORS / 反向代理友好
- 大文件流式上传下载；视频 Range 请求
- 文件内容与目录树解耦存储，便于去重扩展与路径安全
- 数据库 schema 由迁移脚本管理，应用启动校验
- 并发上传同一相对路径文件夹时，创建目录应幂等、不因唯一约束失败

### 1.5 环境需求

- JDK 21+
- Gradle 8.14+
- Node.js 20+
- PostgreSQL 16+（或嵌入式 PostgreSQL）
- （可选）FFmpeg

## 2. 系统设计

### 2.1 总体架构

```
┌─────────────────┐     /api、/webdav      ┌──────────────────────┐
│  kiftd-front    │ ───────────────────►  │  kiftd-backend       │
│  Vue3 + Pinia   │ ◄───────────────────  │  Spring Security JWT │
└─────────────────┘     JSON / 流式字节    └──────────┬───────────┘
                                                     │
                          ┌──────────────────────────┼──────────────────────────┐
                          ▼                          ▼                          ▼
                   PostgreSQL                  文件块存储                  （可选）FFmpeg
                   元数据/账号                 ./data/filenodes             视频转码
```

- **表现层**：SPA；预览以弹窗 `PreviewDialog` / `AppWindow` 为主，另有独立路由页备用。
- **应用层**：Controller → Service → Repository；统一 `ApiResponse` 包装。
- **数据层**：JPA 实体 + Flyway；物理文件为扁平内容块。

### 2.2 逻辑数据模型

```
Account 1──* （操作） Folder / FileNode
Folder  (自关联 parent) 1──* Folder
Folder  1──* FileNode
FileNode.file_path ──► Storage 块 ID（磁盘文件名）
FileChain / DownloadKey ──► FileNode
Propertie (KV) ── notice / notice_md5
```

| 表 | 用途 |
|----|------|
| `account` | 用户与权限串 |
| `folder` | 目录树；`(folder_parent, folder_name)` 唯一 |
| `file_node` | 文件元数据；`file_path` 指向存储块 |
| `properties` | 系统键值（公告等） |
| `file_chain` | 外链 |
| `download_key` | 短时下载钥 |

根文件夹：`folder_id = 'root'`，启动时由迁移脚本种子数据保证。

### 2.3 存储设计

- 逻辑路径仅存在于数据库树中。
- 物理层：`StorageService` 在 `kiftd.storage.root` 下以 UUID 文件名保存内容块。
- 上传 → `saveNewBlock`；复制 → `duplicateBlock`；删除 → `deleteBlock`。
- 路径解析做目录穿越防护（块 ID 不得包含 `..` 等）。

### 2.4 安全设计

```
请求 → JwtAuthFilter（Bearer 或 ?token=）→ SecurityFilterChain
     → Service 内 SecurityUtils.requireAuth(权限)
     → FolderService.checkAccess(folderConstraint)
```

| 面 | 策略 |
|----|------|
| 认证 | JWT；无状态 Session；CSRF 关闭 |
| 授权 | `AccountAuth` 枚举在业务层校验 |
| 目录可见性 | `folderConstraint`：0 公开，≥1 需登录 |
| 密码 | 前端 RSA → 后端解密 → BCrypt |
| 预览媒体 | 允许 `?token=` 以便 `<video>` / iframe 带鉴权 |
| CORS | `kiftd.cors.allowed-origins` 白名单 |

公开接口（过滤器层 permitAll，业务仍可能校验目录约束）：

- `/api/auth/**`、`/api/system/**`、`/api/links/**`
- `GET` 目录 view / remaining / count
- `GET /api/preview/**`
- `/webdav/**`（当前实现为开放访问，部署时需注意网络隔离）

### 2.5 目录浏览与分段加载

1. `GET /api/folders/view?fid=` 返回当前夹、面包屑、首批文件夹/文件（数量 `select-step`）、总数偏移信息。
2. 若总数大于首批，前端再调 `GET /api/folders/remaining` 拉取剩余项。
3. `GET /api/folders/{id}/count` 递归统计子目录数、文件数、总大小，供路径旁展示。

### 2.6 上传流程

**单文件 / 多文件**

1. `POST /api/files/check-upload` 检查重名，返回 `uploadKey` 与冲突列表。
2. `POST /api/files/upload` multipart 上传（可 `overwrite`）。

**文件夹上传**

1. 浏览器 `webkitdirectory` 取得相对路径。
2. 前端按路径段幂等 `createFolder`（服务端 get-or-create + DB 唯一索引）。
3. 文件落入对应 `folderId` 后调用上传接口。

### 2.7 预览管道

```
扩展名判定 (HomeView)
    ├─ 图片 → pictures API + 图库
    ├─ 音频 → audios API + 播放器
    ├─ 视频 → PreviewDialog(video) → /resource Range
    ├─ epub → epubjs + /resource
    ├─ pdf  → /pdf → PDF.js / iframe
    ├─ office → /office-pdf
    └─ 文本/md/html → PreviewDialog(text)
         ├─ md：marked 渲染 + 源码/并排/预览
         ├─ html：sandbox iframe
         └─ 其它：等宽纯文本（UTF-8 / GBK 探测）
```

### 2.8 外链设计

| 类型 | 表 | 典型有效期 | 用途 |
|------|-----|------------|------|
| Chain | `file_chain` | 约 30 天 | 可分享直链 |
| Download Key | `download_key` | 约 1 天 | 短时下载 |

创建需登录且具备下载权限；GET 下载接口公开（凭 key）。

### 2.9 WebDAV

- 挂载路径：`/webdav/**`
- 支持：`OPTIONS`、`PROPFIND`、`GET`、`PUT`、`DELETE`、`MKCOL`
- 未实现：LOCK、COPY、MOVE 等完整 RFC 能力（按「基础同步」定位）

## 3. 实现说明

### 3.1 工程结构

```
file-manager/
├── README.md
├── docker-compose.yml
├── docs/
│   └── 系统需求设计与实现.md    ← 本文档
├── kiftd-backend/
│   └── src/main/java/com/kiftd/
│       ├── controller/     Auth / Folder / File / Preview / Link / System
│       ├── service/
│       ├── entity/ repository/ dto/
│       ├── security/       JwtService、JwtAuthFilter、AccountAuth
│       ├── config/         Security、CORS、嵌入式 PG、管理员初始化、WebDAV
│       ├── webdav/
│       └── util/           StorageService、RSA、验证码等
└── kiftd-front/
    └── src/
        ├── views/          Home / Login / Signup / Video / Epub / Pdf
        ├── components/     PreviewDialog、AppWindow
        ├── api/            http、auth、files
        ├── stores/auth.ts
        └── router/
```

### 3.2 技术选型（当前）

| 层 | 技术 |
|----|------|
| 后端 | Java 21、Spring Boot 3.5.5、Spring Security、Data JPA、Validation |
| 库 | PostgreSQL + Flyway；可选 zonky embedded-postgres |
| 令牌 | jjwt 0.12.x |
| 预览后端 | PDFBox、Apache POI、xdocreport（docx→PDF） |
| 前端 | Vue 3.5、Vue Router 4、Pinia 4、Vite 8、Element Plus、Axios |
| 预览前端 | pdfjs-dist、pdf-lib、epubjs、marked、JSEncrypt |

### 3.3 数据库迁移

| 版本 | 内容 |
|------|------|
| `V1__init.sql` | 建表；种子 `root`；初始公告 |
| `V2__clear_welcome_notice.sql` | 清空欢迎公告 |
| `V3__folder_parent_name_unique.sql` | 合并重复同名目录；唯一索引 `uk_folder_parent_name` |

JPA：`ddl-auto: validate`，以 Flyway 为准。

### 3.4 主要 API 一览

统一响应：`{ code, message, data }`，成功 `code = 0`。

#### 认证 `/api/auth`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/public-key` | RSA 公钥 |
| GET | `/captcha` | 验证码 |
| GET | `/signup-enabled` | 是否开放注册 |
| POST | `/login` `/signup` `/change-password` `/logout` | 账号操作 |

#### 文件夹 `/api/folders`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/view` | 目录视图 |
| GET | `/remaining` | 续载 |
| POST | `/` | 新建（幂等） |
| PUT | `/{folderId}` | 重命名/约束 |
| DELETE | `/{folderId}` | 删除 |
| GET | `/{folderId}/count` | 递归统计 |
| GET | `/search` | 搜索（需登录） |

#### 文件 `/api/files`

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/check-upload` | 上传前检查 |
| POST | `/upload` | 上传 |
| PUT/DELETE | `/{fileId}` | 改名 / 删除 |
| POST | `/batch-delete` | 批量删 |
| GET | `/{fileId}/download` | 下载 |
| POST | `/confirm-move` `/move` | 移动/复制 |
| POST | `/zip` | 打包下载 |

#### 预览 `/api/preview`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/pictures` `/audios` `/video` `/transcode-status` | 媒体元信息 |
| GET | `/resource/{fileId}` | 原始资源（支持 Range） |
| GET | `/pdf/...` `/txt-pdf/...` `/office-pdf/...` | PDF 通道 |

#### 外链 `/api/links` · 系统 `/api/system`

- `POST /chain`、`POST /download-key`；`GET /chain/{key}`、`GET /download/{key}`
- `GET /os`、`/ping`、`/notice`、`/notice/md5`；`PUT /notice`

### 3.5 前端实现要点

| 模块 | 实现 |
|------|------|
| 路由 | `/` 主页；`/login` `/signup`；备用 `/video/:id` `/epub/:id` `/pdf/:id` |
| 鉴权 | Pinia + localStorage；Axios 拦截器挂 Bearer；401 跳转登录 |
| 主页 | 面包屑 + 目录统计同一行；工具栏上传/剪切复制；表格双击打开 |
| 记忆路径 | `localStorage.folder_id`；失效则回退 `root` |
| Markdown | `marked` GFM；布局：源码 \| 并排 \| 预览；源码浅色背景 |
| 代理 | 开发态 Vite 将 `/api`、`/webdav` 代理到后端 |

### 3.6 关键实现要点

| 模块 | 类 / 行为 |
|------|-----------|
| 目录幂等创建 | `FolderService.createFolder`：无外层事务捕获唯一约束；`findFirstBy...` |
| 文件查询 | 同名场景使用 `findFirst`，避免 `NonUniqueResultException` |
| 统计 | `FolderService.countContent` BFS 累加 |
| 文本转 PDF | `PreviewService.writeTxtAsPdf`（遗留通道；前端文本预览已优先走原生） |
| 管理员 | `AdminInitializer` 按配置创建初始账号 |
| WebDAV | `WebDavServlet` 映射到存储与元数据服务 |

### 3.7 配置要点

文件：`kiftd-backend/src/main/resources/application.yml`

| 键 | 含义 |
|----|------|
| `server.port` | 后端端口（当前仓库示例为 `80`） |
| `kiftd.embedded-pg` | 是否嵌入式库 |
| `spring.datasource.*` | 外部库连接 |
| `kiftd.jwt.*` | 密钥与过期小时 |
| `kiftd.storage.root/temp` | 块存储与临时目录 |
| `kiftd.signup.enabled` | 注册开关 |
| `kiftd.ffmpeg.path` | 转码命令 |
| `kiftd.cors.allowed-origins` | 前端源 |
| `kiftd.admin.username/password` | 初始管理员 |
| `kiftd.select-step` | 分段加载步长（默认 100） |
| `kiftd.webdav.*` | WebDAV 开关与路径 |

生产可参考 `application-prod.yml`（关闭嵌入式库，改用外部 PostgreSQL）。

`docker-compose.yml` 默认库：`kiftd` / `kiftd` / `kiftd`，端口 `5432`。若与 `application.yml` 中账号不一致，启动前需对齐。

### 3.8 本地启动（摘要）

```bash
# 可选：外部 PostgreSQL
docker compose up -d

# 后端
cd kiftd-backend
gradlew.bat bootRun

# 前端
cd kiftd-front
npm install
npm run dev
```

- 前端默认：http://localhost:5173  
- 后端端口以 `application.yml` 的 `server.port` 为准  
- WebDAV：`http://<host>:<port>/webdav/`

### 3.8.1 生产 Docker 部署（Ubuntu）

推荐布局 `/opt/apps/kiftd`，三容器：PostgreSQL + JAR（Temurin/Ubuntu）+ Nginx。  
完整步骤见 [deploy/README.md](../deploy/README.md)。

```bash
./deploy/scripts/build.sh
sudo ./deploy/scripts/install.sh
# 编辑 /opt/apps/kiftd/.env
/opt/apps/kiftd/scripts/start.sh
```

### 3.10 已知限制与注意点

1. WebDAV 当前过滤器层开放，生产环境应置于内网或另行加固鉴权。  
2. `PUT /api/system/notice` 在过滤器层公开，生产应限制为管理员。  
3. Office 预览以 docx 为主，ppt/pptx 为降级提示。  
4. 文本预览默认限制约 5MB，超限引导下载。  
5. README 中的端口、管理员账号等描述若与 `application.yml` 不一致，**以配置文件与本文档「实现」节为准**。
